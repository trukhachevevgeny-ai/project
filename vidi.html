Виды алгоритмических конструкций

Любой алгоритм можно собрать из трёх базовых «кирпичиков» — следования, ветвления и цикла. А если разрешить функции вызывать самих себя, добавляется четвёртый — рекурсия.

1. Линейный алгоритм — следование

Команды выполняются одна за другой, сверху вниз, ровно по одному разу. Никаких условий и повторов.

  • Самый простой вид конструкции
  • Порядок команд критичен
  • Пример: «прочитать число → умножить на 2 → вывести результат»

Команда 1
Команда 2
Команда 3
Конец

2. Ветвление — условие

Алгоритм проверяет условие и в зависимости от результата идёт по одной из двух ветвей. Выполняется только одна из них — либо «да», либо «нет».

  • Ключевое слово: if … then … else
  • Условие — логическое выражение: истина или ложь
  • Пример: «если число чётное — вывести 0, иначе — 1»

Условие?
ДА

НЕТ
Действие B
Конец

3. Цикл — повторение

Одно и то же действие выполняется несколько раз, пока условие остаётся истинным. Когда условие становится ложным — алгоритм идёт дальше.

  • Ключевые слова: for, while, repeat
  • Обязательно должно быть условие выхода
  • Пример: «вывести числа от 1 до 3»

4. Рекурсия — вызов себя

Функция внутри своего тела вызывает саму себя — но с другими аргументами. Так продолжается до тех пор, пока не сработает базовый случай, который остановит цепочку.

  • Обязателен базовый случай (условие остановки)
  • Каждый вызов уменьшает задачу
  • Пример: count(3) → count(2) → count(1) → count(0) → стоп
count(3)
count(2)
count(1)
count(0) — стоп
Каждый вызов «уходит вглубь», пока не достигнет базового случая

Три кирпичика — и один особый

Любой, даже самый сложный алгоритм строится из этих четырёх конструкций. Комбинируя их, можно описать программу для решения любой задачи — от простого калькулятора до искусственного интеллекта.

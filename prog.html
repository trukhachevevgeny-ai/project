Программы и программное обеспечение

Компьютер сам по себе — просто набор микросхем. Чтобы он начал что-то делать, ему нужны программы — последовательности команд, написанные человеком.

Программа — это последовательность команд, которую выполняет компьютер в процессе обработки информации.

1. Что такое программа — цепочка команд

Программа похожа на рецепт: набор простых шагов, которые нужно выполнить по порядку. Каждая команда говорит процессору, что делать прямо сейчас.

  • Команды выполняются в заданном порядке
  • Компьютер не «думает» — он просто исполняет
  • Без программы компьютер бесполезен

2. Программное обеспечение — набор программ

Все программы компьютера вместе называются программным обеспечением (ПО). Его делят на три большие группы.

  • Системное ПО — управляет «железом» (операционная система)
  • Прикладное ПО — программы для пользователя (браузер, игры)
  • Инструменты — программы для создания программ

3. Как программа попадает в компьютер — компиляция

Программист пишет код на понятном человеку языке, а специальная программа-компилятор переводит его на язык машинных команд — в исполняемый файл.

  • Исходный код читает человек
  • Компилятор переводит его в машинный код
  • Компьютер исполняет готовый файл

Программа — душа компьютера

Без программ любая техника — просто металл и пластик. Программы превращают компьютер в рабочего инструмент, в учителя, в игровую приставку. И каждую из них когда-то написал человек — такой же, как вы.
